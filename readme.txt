Make sure you have CUDA and latest Nvidia driver installed, Nvidia Background TOP requires both of them in order to work:

https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-sdk/resources/ ( VIDEO EFFECTS SECTION )
https://www.nvidia.com/en-us/geforce/drivers/

-----------------

To change the gap between the clones, go to Switch TOP parameters, change the number 8 in " 1 if me.time.frame % 8 == 0 else 0 " to your liking, it represents after how many frames the effects triggers again.

-----------------

Press Reset in Feedback TOP parameters to trigger the effect on & off.

-----------------

Change direction of the trail by swapping between negative and positive values in the Transform TOP in the feedback loop.

-----------------

For Spoutcam use ( Streaming to Google Meet, Twitch or whatever ) make sure the final output is 8-bit pixel format, Spoutcam link: https://spout.zeal.co/
